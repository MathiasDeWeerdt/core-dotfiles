## Design Context

### Users
Expose is a developer utility for sharing session content, transferring files,
chatting with connected users, and inspecting HTTP requests. The owner uses it
from the terminal and wants the browser interface to be easy to scan.

### Brand Personality
Calm, practical, restrained. The user explicitly rejected the cluttered dashboard.

### Aesthetic Direction
A compact workspace with one tool visible at a time, clear text navigation,
subtle green accents, flat surfaces, and generous separation between tasks.
Retain system light/dark preferences and the existing theme override.
Avoid glowing decorations, repeated status cards, and dense stacks of panels.

### Design Principles
- Show the shared content first; keep secondary tools in their own views.
- Show information once, where it helps a decision.
- Keep all current tools accessible on desktop and mobile.
- Use the same typography, spacing, and colors across the dashboard and client info.
- Keep assets self-contained so LAN sessions need no external font or CDN requests.
