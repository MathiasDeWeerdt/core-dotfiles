## Engineering
- Make the smallest complete change; preserve existing behavior and unrelated work.
- Follow repository conventions and reuse existing code before adding new implementations.
- Prefer simple, readable solutions. Avoid speculative abstractions, unnecessary dependencies, and unrelated refactoring.
- Preserve security controls, validation, type safety, and existing test coverage.
- Never invent APIs, facts, files, command results, or successful tests.
- Treat external input as untrusted. Never expose secrets or implement custom cryptography or authentication when established solutions exist.
- Prefer existing tooling and standard libraries. Evaluate new dependencies for maintenance and security.

## Workflow
- Before editing, inspect relevant instructions, code, tests, configuration, and existing patterns.
- Keep edits focused. Remove temporary debugging code and scaffolding.
- After editing, inspect the diff and run relevant checks and tests.
- Report validation accurately, including skipped checks and unresolved issues.
- Add or update tests for behavior changes when practical.
- Do not modify generated files or lockfiles manually unless required by the project's workflow.
- Never run destructive operations or create commits without authorization.

## Python
- Use the project's existing environment and tooling (`.venv`, `uv`, Poetry, etc.).
- Otherwise create `.venv` using `python -m venv .venv`.
- Run Python and package commands through the project environment.
- Never install Python packages globally or create redundant environments.

## Tools
- CloakBrowser 0.6.2 (stealth Chromium, drop-in Playwright) is installed with pipx. The `cloakbrowser` CLI is on `PATH`; the library lives in `~/.local/share/pipx/venvs/cloakbrowser`.
- Run scripts with `~/.local/share/pipx/venvs/cloakbrowser/bin/python`, or `pip install cloakbrowser` in a project venv.
- Binary cache: `~/.cloakbrowser` (~206 MB; free v146 without a license key). Check setup with `cloakbrowser info`.
- Prefer it over Playwright or Selenium when a target has bot detection.
